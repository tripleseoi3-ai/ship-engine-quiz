# server — 프론트엔드와 백엔드를 나눈 시험노트

앞서 만든 `시험대비.html` 은 **파일 하나**였다. 브라우저가 전부 다 했다 —
문제도 정답도 채점도 그 파일 안에 있었다. 그래서 소스를 열면 답이 다 보였다.

여기서는 **둘로 나눴다.**

| | 어디에 있나 | 무엇을 하나 |
|---|---|---|
| **프론트엔드** | `public/` 의 `index.html` · `style.css` · `app.js` | 화면을 그린다. 자료도 정답도 없다. 서버에 물어본다 |
| **백엔드** | `server.js` · `lib/study.js` | 자료를 가지고 있고, 문제를 만들고, **채점한다** |

---

## 켜는 법

검은 창(PowerShell)에서 이 폴더의 **한 단계 위**로 가서:

```
node server/server.js
```

이렇게 뜨면 성공이다.

```
  시험노트 서버가 떴습니다.
  주소 : http://localhost:3000
```

브라우저에서 **http://localhost:3000** 을 연다.

**끄는 법** — 그 검은 창에서 `Ctrl+C`.
**포트를 바꾸려면** — `set PORT=4000 && node server/server.js`

> 창을 닫으면 서버가 꺼지고 화면도 안 열린다. 공부하는 동안은 창을 켜 둔다.

---

## 왜 나눴나 — 정답이 브라우저로 안 내려간다

이게 이 구조의 핵심이다. 문제를 받을 때 응답은 이렇게 생겼다.

```json
{ "index": 0, "type": "blank", "typeLabel": "빈칸",
  "prompt": "관계식으로 정리하면 ____ = 나침방위 + 자차 + 편차가 된다.",
  "choices": null }
```

**`answer` 가 없다.** 정답은 서버 메모리에만 있다.
답을 보내야 그때 채점 결과와 함께 정답·해설·출처가 내려온다.

```json
{ "correct": true, "answer": "진방위",
  "why": "원문은 「관계식으로 정리하면 진방위 = …」입니다.",
  "source": "항해학 기초 · 2. 방위와 침로",
  "gradingRule": "띄어쓰기와 조사 차이는 정답으로 처리합니다." }
```

즉 **페이지 소스를 봐도 답을 미리 볼 수 없다.** 파일 하나짜리로는 못 하던 일이다.

`server.js` 의 `forClient()` 함수가 그 경계다. 문제에서 정답·해설·출처를 떼어내고
프론트에 보낼 몫만 남긴다.

## API

| 메서드 | 주소 | 하는 일 |
|---|---|---|
| GET | `/api/health` | 서버가 살아 있는지 |
| GET | `/api/subjects` | 과목 목록 |
| POST | `/api/subjects` | 과목 등록 `{ name, raw }` |
| GET | `/api/subjects/:id` | 정리(핵심 + 원문) + 학습 현황 |
| DELETE | `/api/subjects/:id` | 과목 삭제 |
| POST | `/api/subjects/:id/quiz` | 시험 시작 `{ mode: "new" \| "wrong" }` → **정답 없는** 문제 묶음 |
| POST | `/api/quiz/:sid/answer` | 채점 `{ index, given }` → **여기서 정답이 내려온다** |
| GET | `/api/subjects/:id/wrongs` | 오답 목록 |
| DELETE | `/api/subjects/:id/wrongs` | 오답 비우기 |

화면 왼쪽 **「서버와 주고받은 것」** 칸에 이 요청들이 실시간으로 찍힌다.
버튼을 누를 때마다 무엇이 오가는지 눈으로 볼 수 있다.

## 저장

`data/db.json` 파일 하나에 저장한다. 서버가 알아서 만든다.

- **인터넷으로 나가지 않는다.** 이 컴퓨터 안에만 있다.
- 깃허브에도 안 올라간다 (`.gitignore` 로 막아 두었다). 공부 기록은 개인 자료다.
- 백업하려면 그 파일을 복사해 두면 된다.

**풀던 시험은 서버 메모리에만 있다.** 서버를 끄면 진행 중이던 회차는 사라진다.
등록한 과목과 오답은 파일에 있으니 남는다.

## 안 되면

| 증상 | 원인과 해결 |
|---|---|
| `'node'은(는) ... 인식할 수 없습니다` | Node.js 가 없거나 창이 오래됐다. 검은 창을 새로 열고 다시 해 본다 |
| `3000번 포트를 이미 다른 프로그램이 쓰고 있습니다` | `set PORT=4000 && node server/server.js` 로 다른 포트를 쓴다 |
| 화면 왼쪽 위가 **서버 없음** | 검은 창이 꺼졌다. 다시 켠다 |
| 문제가 4종 안 나옴 | 자료에 표나 「용어: 설명」 줄이 적다. 화면이 어떤 유형을 왜 못 만들었는지 알려준다 |
