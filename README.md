## 앱에 무엇이 있나

화면 다섯 개다. 왼쪽 메뉴로 옮겨 다닌다.

| 화면 | 하는 일 |
|---|---|
| **오늘** | 첫 화면. 오늘 복습할 오답 · 남은 할 일 · 오늘 계획 · 가장 가까운 시험 D-day |
| **플래너** | 과목마다 시험일을 정하고, 주간 계획을 하루 한 줄씩 본다. **자료의 절을 남은 날짜에 자동으로 나눌 수 있다** |
| **할 일** | 과목과 마감일을 붙인 투두리스트 |
| **학습 기록** | 연속 학습일 · 최근 14일 푼 문항 · **자주 틀리는 절** · 회차별 점수 |
| **과목** | 학습 자료(요약 + 원문 펼치기) · 문제 풀이 · 오답 노트 |

문제는 **객관식 · OX · 주관식 · 빈칸** 4종이 섞여 한 번에 10문항 나온다.
**모의고사**를 고르면 20문항을 중간 채점 없이 시간을 재며 푼다.

틀린 문제는 오답 노트에 쌓이고 **1 · 3 · 7 · 14일 간격으로 다시 올라온다.**
맞힐 때마다 한 단계 올라가고 **4단계를 넘기면 목록에서 빠진다.** 다시 틀리면 1단계로 돌아간다.

과목 · 오답 · 계획 · 할 일 · 학습 기록은 **접속한 사람의 브라우저 안에만** 저장된다.
어디로도 전송되지 않는다. 다른 기기로 옮기려면 왼쪽 `보관` 에서 파일로 내보낸 뒤 그 기기에서 불러온다.

## 실행

```
npm run build     web/ 와 server/ 에서 site/ 를 만든다
npm run preview   만들어진 site/ 를 http://localhost:4173 에 띄운다
npm start         프론트/백엔드를 나눈 로컬 서버 버전 (http://localhost:3000)
```

`시험대비.html` 과 `app/exam-notebook.html` 은 **두 번 눌러 브라우저로 바로 열린다.** 서버가 필요 없다.

## 이 저장소를 읽는 순서

1. `01-interview.md` — 사용자가 실제로 무엇을 말했나 (다듬지 않은 원문)
2. `02-goal.md` — 그 말이 어떤 결정으로 굳었나. 폐기된 결정도 지우지 않고 남겼다
3. `03-spec.md` — 명세를 건너뛰면서 무엇이 문서 없이 코드 안으로 들어갔나
4. `app/exam-notebook.html` — 그 결과
5. `web/` — 그 뒤로 얹은 것 (오늘 · 플래너 · 할 일 · 학습 기록 · 복습 주기 · 모의고사).
   02-goal.md 의 "2차 이후" 로 미뤄 두었던 **복습 주기 / 진도 관리**와 **오답 통계**가 여기서 들어왔다

3번이 이 저장소에서 가장 정직한 문서다. 명세 없이 구현으로 건너뛴 대가가
무엇인지(요구사항 ID 없음, 추적표 없음, 테스트 없음) 그대로 적혀 있다.
