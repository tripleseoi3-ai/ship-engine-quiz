## 승인 전 점검

- [ ] 모든 REQ가 골/지표로 되짚어진다
- [ ] 모든 지표를 커버하는 REQ가 있다
- [ ] 모든 REQ에 시나리오가 최소 1개 있다
- [ ] 입력마다 "잘못된 값이 들어오면?" 이 적혀 있다
- [ ] 비목표가 REQ로 새어 들어오지 않았다
- [ ] 미결정마다 답할 사람이 적혀 있다
